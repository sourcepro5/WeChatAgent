# 前台模拟输入发送（实验）

前台模拟输入通过键盘操作所选的干净微信客户端，文字和文件的送达状态由微信数据库回执确认。Windows x64 安装包已内置运行依赖。默认发送后端为 Hook。

流程与开源项目 Akasha-WeChat 的键盘方案相同（`Ctrl+F` 搜索、粘贴、回车），不使用 OCR，不点鼠标。另外加了下面“发送约束”里的检查。

## 启用

1. 从托盘彻底退出正在运行的微信。同一账号同一时间只能登录一个客户端，带 Hook 的客户端也要先退出。
2. 打开“设置 → 连接设置 → 微信发送方式”：
   - 安装版可直接用内置 Python。需要检查时，点击“检查模拟输入依赖”。源码运行时，该按钮在 `state/input/venv` 准备独立环境；
   - 发送后端选“前台模拟输入（实验，无 OCR）”；
   - “模拟输入使用的干净微信”留空可沿用当前选定的匹配微信，也可手选官方 `Weixin.exe`。前台模式要求微信进程未加载 Hook，且目录无代理 DLL；
   - “发送按键”与微信“设置 → 快捷键 → 发送消息”保持一致；
   - 保存设置。
3. 点击“打开匹配微信”。input 模式只原样打开所选客户端，不注入任何组件。登录后保持主窗口打开（最小化可以，不能只留在托盘）。
4. 点击“检查当前发送方式”，通过后重启后台服务。

切回原生发送：退出微信，发送后端改回“原生发送（Hook）”，保存，再按 Hook 方式打开微信并重启服务。`hook.*` 设置不受影响。

## 单次发送做什么

1. 用 Windows 互斥锁串行执行。按所选程序路径找到唯一进程和唯一主窗口，核对它打开的唯一账号数据库与读取器账号一致，并确认进程里**没有**任何 WeChatAgent Hook 模块（`wechatagent-*.dll`，或客户端目录下的 `version.dll`）。
2. 检查暂停开关和白名单。你在最近 `idleMs`（默认 2 秒）内操作过键鼠时，先不发送，稍后重试。
3. 记下当前前台窗口和剪贴板内容，把微信切到前台（必要时从最小化还原）。
4. 按 `Ctrl+F`，粘贴读取器解析出的聊天名称，回车进入聊天。
5. 在输入框按 `Ctrl+A`、`Ctrl+C`，检查有没有草稿。有草稿就中止。如果复制到的正是搜索词，说明没找到聊天，按 Esc 关闭搜索后中止。
6. 粘贴正文，再用 `Ctrl+A`、`Ctrl+C` 取回，必须与正文完全一致。
7. 重新读取设置并核对进程、账号和前台窗口都没变，然后按 `Ctrl+End` 和发送键提交，并确认输入框已清空。
8. 恢复剪贴板（期间你又复制过别的内容时不覆盖），切回原来的前台窗口。

最终是否送达，由原有的数据库新消息 ID 和服务器 ID 回执决定。已经按过发送键的同一投递只核对回执，不会再按一次。

## 发送约束

- **没有 OCR，靠名称唯一保证找对人**：聊天名称不能出现在任何其他联系人或群的名称里。例如白名单里有“小明”，同时存在“小明同学”，就会拒绝发送（`INPUT_TARGET_AMBIGUOUS`）。请在微信里给目标设置一个唯一的纯文字备注名，再同步读取器。
- 发送时会占用前台和键盘约 1–3 秒。你在打字或切换窗口时，操作会中止（`INPUT_FOREGROUND_CHANGED`），并按队列稍后重试。
- 锁屏、微信只在托盘、远程桌面断开时无法发送。
- 一次只发一个聊天。常规前台模式支持文字和普通文件。前台录音选项仅限微信 4.2.0.12 的文件传输助手，并需单独配置 VB-CABLE。[实验性前台录音](VOICE_OUTPUT.md#实验性前台录音)
- 模拟按键在系统里带有“注入”标记，微信理论上能识别。

## 常见错误

| 错误 | 处理 |
| --- | --- |
| INPUT_DEPENDENCIES_MISSING | 安装版可留空模拟输入 Python 路径并检查内置依赖。源码运行时点“检查模拟输入依赖”准备环境 |
| INPUT_CLIENT_REQUIRED / INPUT_CLIENT_INVALID | 选择干净的 `Weixin.exe` |
| INPUT_CLIENT_HAS_PROXY_DLL | 客户端目录里有 `version.dll`，请换一个干净目录 |
| INPUT_CLIENT_HAS_HOOK | 微信进程加载了 Hook 模块：从托盘退出微信，用“打开匹配微信”重新打开 |
| INPUT_OTHER_WECHAT_RUNNING | 其他微信（例如 Hook 客户端）还在运行，先退出 |
| INPUT_WECHAT_NOT_RUNNING / INPUT_ACCOUNT_UNVERIFIED | 打开所选微信并登录 |
| INPUT_WINDOW_NOT_READY / INPUT_WINDOW_NOT_VISIBLE | 从托盘恢复微信主窗口（最小化可以） |
| INPUT_ACCOUNT_MISMATCH | 微信登录的账号与读取器账号不同 |
| INPUT_TARGET_AMBIGUOUS | 为目标设置唯一备注名并同步读取器 |
| INPUT_TARGET_NOT_FOUND | 搜索没有结果，核对备注名 |
| INPUT_DRAFT_PRESENT | 输入框里有你的草稿，先发出或清空 |
| INPUT_CONTENT_MISMATCH | 粘贴结果与正文不一致，已清空输入框，不会发送 |
| INPUT_USER_ACTIVE / INPUT_DESKTOP_BUSY | 你正在操作电脑或有其他发送在进行，稍后自动重试 |
| INPUT_FOREGROUND_DENIED / INPUT_FOREGROUND_CHANGED | 无法切到微信，或中途被切走，稍后重试 |
| INPUT_SUBMIT_UNCONFIRMED | 按了发送键但输入框没清空。请核对“发送按键”设置；该投递只核对回执 |
| INPUT_SEND_UNCONFIRMED | 已按发送键但结果未知，请核对微信与数据库记录；该投递只核对回执 |
