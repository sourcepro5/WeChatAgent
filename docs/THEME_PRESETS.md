# 主题预设 · 罗德岛 PRTS / 冻土与火种

控制台除默认的液态玻璃外，另提供两个《明日方舟》风格的主题预设。

顶栏"更多" → 主题预设中有三个选项：

| 预设 | 说明 |
| --- | --- |
| 液态玻璃 | 默认主题 |
| 罗德岛 · PRTS | 《明日方舟》游戏内界面系统 |
| 冻土与火种 | 在 PRTS 系统之上叠加 7.5 周年 · 2026 感谢庆典活动皮肤 |

## 为什么分两层

第一版只参考了活动宣传网页。活动页的氛围几乎全靠大幅插画，界面本身只是深色加橙色；去掉插画后，剩下的东西认不出是方舟。
方舟的辨识度来自游戏内那套界面系统。所以现在先实现"罗德岛 · PRTS"这套系统，活动只作为一层可替换的皮肤盖在上面。

## 方舟界面系统的设计依据

参考《〈明日方舟〉UI/UX 分析——藏在好看背后的先进性》（真经阁，indienova 等转载）、官网与活动页实测：

| 设计点 | 方舟中的做法 | 控制台中的落地 |
| --- | --- | --- |
| 画内界面 | 主看板是 PRTS 投射在视野里的悬浮窗口，随陀螺仪移动；时间、电量、信号放进同风格浮窗 | 倾斜的"主看板"大方块，随指针视差，可作为独立主界面或嵌入概览（见下文）；顶栏 HUD 显示 `PRTS ONLINE / 日期 / 时间` |
| 材质与层级 | 类 Fluent 的亚克力毛玻璃，层级对比极高；次级页面以浮窗覆盖在模糊的原页面上 | 深色亚克力直角面板；主控卡用白底黑字；弹窗叠在模糊、去饱和的页面上 |
| 字体 | 标题思源宋体，正文思源黑体，技术文字用工业风伪等宽体 Bender，拉丁展示字用古典衬线 | Noto Serif SC / Noto Sans SC；Bender 用 Windows 自带的 Bahnschrift 代替 |
| 中英并置 | 大量装饰性英文与临床风小字 | 每页一个巨大英文词（TERMINAL / CHANNELS / OPERATOR…）+ 宋体中文标题 + 代号（PRTS-TML）+ 页码 |
| 底图 | 噪点、漫画网点、警戒线粗条纹、暗角 | 背景网点、斜纹、噪点、暗角；警示横幅、未保存栏、未启动的主控卡用黄黑斜纹 |
| 色彩 | 黑白灰为主，蓝、橙为辅，警戒亮色 | 黑/白/灰 + PRTS 蓝主色，黄色警示，红色错误 |
| 图形 | 矩形为主，少量圆形；十字、三角标记 | 全部直角；卡片左上十字定位标、右上主色短条；导航选中项白块 + 三角箭头 |
| 动效 | 独立系统间深色淡出淡入，相关页面缩放，局部横移淡入；面板角落光线变化、飘浮尘埃 | 切页时 PRTS 深色转场与加载条；内容横移淡入；标题乱码解码；主看板方块依次展开；按钮悬停黑白反相；角落光线、尘埃 |

## 主看板的两种布局

主看板（倾斜的系统入口方块）有两种布局，在顶栏"更多 → 主看板"中切换。这一组选项只在方舟预设下出现，选择保存在本机。

| 布局 | 位置 | 说明 |
| --- | --- | --- |
| 独立主界面（默认） | 单独一页 `#prts` | 像游戏的主界面，占满窗口并隐藏侧边栏与工作区，不会和侧边栏的导航同时出现。左侧显示大号时钟、服务状态与三个关键数字，右侧是 7 个入口方块，第一个大块"控制台"进入概览。从侧边栏顶部的"HOME 主界面"进入，按 Esc 或点"控制台"返回 |
| 嵌入概览 | 概览页顶部 | 原来的做法：概览页顶部一排 6 个快捷方块 |

- 使用"独立主界面"布局时，程序启动（没有指定页面）默认进入主界面；如果这台电脑还需要首次配置，则改进入配置页。
- 切到"独立主界面"时会直接打开主界面，切到"嵌入概览"时停留在当前页。
- 控制台本身不认识 `#prts`，会在主界面下方照常渲染概览。主界面上的状态与数字直接从概览的元素里读取，每秒更新，不另调接口。
- 在"嵌入概览"布局或其他预设下打开 `#prts`，会改回 `#overview`。
- 桌面应用中，主界面顶部的一条可以拖动窗口，右侧留出原生窗口按钮的位置。

## 立体卡片

方舟的卡片不是平面色块，而是一块块有厚度的面板：光从左上方来，右下方露出侧面；关键面板背后还垫着一块错开的色板。浮起的卡片可以点，平放的面板只是容器。控制台按这个规则分了层级：

| 层级 | 元素 | 表现 |
| --- | --- | --- |
| 薄板（3px） | 普通内容卡、表单面板、连接节点 | 只有侧面，不浮起 |
| 可交互（4–7px） | 主看板方块、主控卡、指标卡、人格、聊天、工作模式、表情、扩展 | 悬停时浮起 3px，并随指针微倾（指针所在一侧下沉）；整块可点的元素按下时压回底座 |
| 选中 | 当前人格、聊天、工作模式 | 白色面板保持浮起，侧面换成主色 |
| 错位色块 | 主控卡（未运行为警示黄，正常运行为主色）、主看板左上大块 | 背后垫一块向右下错开的色板 |

其他细节：
- 侧面颜色随面板变化：深色面板用比底色亮一档的灰（否则在深色背景上看不出厚度），白色面板用灰色，主色面板用深一档的主色。
- 人格列表做成干员卡：左侧分段的"稀有度"条，右下大号编号 01、02…
- 主控按钮改为带文字的方块按钮，下方附英文小字（ENGAGE / STANDBY）。未运行或需重试时为主色实心；运行中"停止服务"为白底黑框。
- 入场时，卡片像被"发"到桌面上：从左下带一点纵深旋转落下，厚度随之升起。主看板方块展开时，厚度同样从 0 升起。

实现上，厚度是一个注册过的长度属性 `--ark-d`，box-shadow 用它逐级叠出侧面。面板位移等于"静止厚度 − 当前厚度"，所以浮起或按下时侧面的底边不动，看起来像面板离开或压回底座。错位色块的偏移也按厚度计算，会留在底座上。倾斜角 `--ark-rx/--ark-ry` 由 `theme-presets.js` 写入：窄卡片倾斜角大，宽面板倾斜角小。系统开启"减少动态效果"时不倾斜。

## 活动皮肤：冻土与火种

取材于 SideStory「时间啊，向前！」与网页活动「冻土与火种」（乌萨斯题材）。主色换为余烬橙红，配金色发丝线。
氛围层的参数取自活动页实测的关键帧：

| 动效 | 活动页参数 |
| --- | --- |
| 灰烬 | 2px，下落 260px，漂移 -22px，旋转 -20°→35°，10–14s |
| 火星 | 上升的发光颗粒，7–11s |
| 余烬辉光 | 透明度 0.24–1 不规则闪烁，13.4s |
| 雪雾 | ±13.5px 漂移，17.1s |
| 信号故障 | 每 7.6s 一次：位移 3.75px，透明度 .65，红/青色差 |

## 实现

- `public/console/theme-presets.css`：预设选择器；方舟界面系统写在 `html[data-ark]` 下，活动皮肤写在 `html[data-preset=embers]` 下，覆盖控制台与液态玻璃的设计令牌。
- `public/console/theme-presets.js`：以普通脚本在 `<head>` 加载，首屏前写入已保存的预设，不会闪回默认主题。负责：
  - 在顶栏"更多"菜单加入预设选择器；
  - 创建装饰层、顶栏 HUD、主看板（独立主界面或嵌入概览，以及布局选择器）、深色转场；
  - 标题与英文大字的乱码解码；
  - 立体卡片随指针的倾斜；
  - 切换时的水平擦除转场。窗口隐藏时转场超时后直接应用，连续点击以最后一次为准。
- 保存位置：预设、主看板布局，以及进入方舟预设前的明暗，在桌面应用里存进它的偏好文件（与明暗主题、背景图同一处，经 `desktop:preset`）。桌面应用每次启动的端口不同，而 localStorage 按端口隔离，退出后会读不到。在浏览器里打开控制台时仍用 localStorage。
- 方舟预设固定深色底：进入时切到深色并记住原来的明暗，退出时恢复；预设期间隐藏明暗切换按钮。桌面应用会随之把窗口按钮图标切为浅色。
- `public/console/index.html` 与 `scripts/console-server.mjs` 各增加两项登记（引用与静态文件白名单）。

## 注意

- 字体：Bahnschrift 与 Noto Serif/Sans SC 在没有安装的电脑上会回退到系统字体。如需一致效果，可随应用附带字体子集（均为 OFL 许可）。
- 修改主题文件后，记得同步到 `release` 与安装版副本。
