# 微信程序与版本选择

连接设置中的“匹配微信程序位置”和“匹配微信版本”作为一组保存。选择 Weixin.exe 时自动读取精确文件版本、核验启动器与核心的腾讯数字签名，并检查对应原生组件的配置和哈希。手动填写路径时，在保存设置时执行相同检查。版本由实际程序确定，不从目录名猜测。

选择取消、版本不支持、核心缺失或版本不一致、配套组件未准备就绪时，不保存这次切换。检查期间如其他窗口修改设置，返回冲突并要求刷新，防止覆盖新配置。检查不会启动微信、加载 DLL、发送消息或修改账号凭据。

升级和旧数据迁移仍保留已有客户端选择，不自动把旧账号切换到另一套微信。若迁移来的路径已失效，在连接设置中重新选择已准备的匹配客户端并保存；界面会同时更新版本。各发行版只接受自身已经适配、组件已经准备好的精确版本。
