# WeChatAgent 0.4.1+

## 新增功能

- **微信语音识别**：新增独立的语音识别插件 1.2.0，将收到的微信语音转写后交给原聊天模型处理。识别服务地址、密钥和模型均可自行配置。
- **识别模型自动读取**：支持从 API 获取模型列表并选择模型，兼容模型数组与别名映射；服务不提供列表时可手动填写。
- **语音配置检测**：新增内置测试短句、音频转换检查及最近语音状态展示，区分接口连通、模型可用和实际转写结果。
- **会话上下文修复入口**：在“聊天 → 历史与用量”中增加“修复上下文”，用于恢复异常的人格前缀，保留原会话 ID、历史和权限。

## 修复问题

- **会话异常不回复**：兼容 DSH 历史中的新版 system 快照，修复误报 `HISTORY_NATIVE_PREFIX_MISSING` 导致私聊、群聊无法回复的问题。
- **助手启动与群友聊天失败**：修复预设尚未就绪及请求中 `toolChoice` 字段引发的校验失败，保留群友聊天与管理员任务的权限边界。
- **插件权限和宿主不一致**：统一安装校验、控制台、DSH 宿主和插件进程的权限与能力声明，补齐语音读取能力，并明确提示旧宿主缺失的能力。
- **并发语音识别失败**：修复超过两条并发时额外语音被直接判为不可用的问题，改为有界排队处理。
- **语音状态误判**：修复更换接口、密钥或模型后沿用旧检测结果，以及旧的合成测试成功状态遮蔽实际转写失败的问题。
- **增强版更新检查**：修复无法识别 `0.4.1+` 版本及带 `+` 下载地址的问题，避免版本判断错误或下载入口失效。

## 优化内容

- **语音 API 适配**：分开管理协议、服务地址和模型，统一鉴权、路径拼接及结果解析；支持文件转写、Chat 音频 Base64、Chat 音频 Data URL 和自定义请求。
- **语音解码与配置校验**：内置轻量 SILK→WAV 解码组件，兼容安装版 Python 3.13；增加空模型、密钥格式、请求映射及 WAV 格式检查，无需额外安装本地识别模型。
- **语音处理顺序与诊断**：同一聊天保持消息顺序，停止服务时取消等待；失败时明确提示“语音已收到但转写失败”，保留具体错误码。
- **助手能力说明**：依据当前实际工具和授权描述可用能力，减少沿用旧聊天中“做不到”的结论，闲聊不强制调用工具。
- **表情下载诊断**：资源缺失且 CDN 下载关闭时，明确记录原因和对应设置，避免把配置问题统一归为图片读取失败。
- **发布包一致性**：将语音插件、解码组件、检测音频和宿主文件纳入统一打包清单与哈希校验，减少开发目录正常而安装版缺少文件的问题。
