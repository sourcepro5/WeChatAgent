# WeChatAgent 0.4.5

相较于 0.4.3 的更新，适用于 Windows 10/11 x64。[下载安装与校验文件](https://github.com/sourcepro5/WeChatAgent/releases/tag/v0.4.5)

## 新增功能

- **内置语音识别 API 1.6.0** 随 Windows 安装包预置。全新安装后可在「能力 → 能力目录」直接配置。插件默认关闭，填写识别服务并授权聊天后即可启用。
- **内置语音对话 API 1.7.0** 随安装包预置，默认关闭。语音合成、实时语音识别和单条语音识别可分别选择提供商或自定义 API。使用 DSH 回复模式时，沿用当前聊天的人格与上下文，由聊天模型逐轮选择文字或语音。[语音配置](https://github.com/sourcepro5/WeChatAgent/blob/v0.4.5/docs/VOICE_OUTPUT.md)
- **合成与音色**。在专用 TTS 和 Realtime 朗读之间切换时，各自保留模型与音色。千问 / 阿里云百炼的兼容服务提供复刻音色创建、审核状态查询、试听与应用。
- **微信 4.2 原生语音发送** 随安装包提供。使用匹配的微信 4.2.0.12 登录后，已配置的语音对话插件可发送微信原生语音气泡。同一 Hook 已在文件传输助手核对文字、图片、动画表情和语音的服务器回执。
- **前台模拟输入（实验）**。随安装包提供运行依赖，可在“设置 → 连接设置 → 微信发送方式”切换。使用未加载 Hook 的微信发送文字和普通文件，并按微信数据库回执确认送达。实验性前台录音需要 VB-CABLE，目前限 4.2.0.12 的文件传输助手。[前台模式设置](https://github.com/sourcepro5/WeChatAgent/blob/v0.4.5/docs/FOREGROUND_INPUT.md)

## 修复问题

- **旧账号配置导致原生语音被拒绝** 修复读库设置使用带后缀的账号目录名时，Hook 无法核对发送账号的问题。适配器从已核验的目录名提取实际账号 ID，并按正确的发送者匹配数据库回执。
- **语音回执丢失与重复投递** 提交响应丢失时，按原投递记录查询结果。确认语音未提交时可回退为文字。提交结果不确定时继续查询回执，避免重复发送。

## 优化内容

- **语音设置按需展开** 首页显示三项语音能力的当前配置，可直接添加、编辑、试听或测试。打开编辑时只展开选中的能力，默认地址和协议等细节收在「高级设置」。
- **语音识别设置引导** 常用平台可预填地址和推荐模型，填写密钥后即可用内置短句测试。模型列表不可用时仍可手动填写。
- **升级保留现有配置** 已安装的同名语音识别插件及其设置继续保留。语音对话插件读取旧配置时保留已保存的模型、音色、密钥和聊天授权。

## 安装与升级

升级前停止服务，完整退出 WeChatAgent、DSH 和匹配微信。原位置升级沿用已有数据目录。安装后按引导准备连接配置，从托盘退出并重开 DSH，再启动服务。[安装说明](https://github.com/sourcepro5/WeChatAgent/blob/v0.4.5/docs/INSTALLER_RELEASE.md)
