# 原生表情包发送

仅使用当前账号、当前白名单聊天中已收到并完成准备的表情资源，模型通过短编号选择，不提供任意路径或 XML。动态 GIF 保留原始字节，静态 PNG/JPEG/WebP 转换为发送所需 GIF；未支持的动画格式不作为发送候选。

只有目标聊天出现新的资源 MD5 匹配记录及非零服务器消息 ID 才确认成功。支持 emoji-47 与经 XML 验证的 appmsg-8 回执，普通文件卡片和旧消息不能确认。未确认请求先核对迟到回执，避免重复发送。

桌面“回复设置”管理全局发送与标签缓存，“聊天范围”支持单独聊天覆盖。开关保存后生效，不修改人格卡或历史。标签随正常识图学习，随后优先复用文字标签，失败图片不学习标签。

标签、资源与验收记录均保存在本机 state/，不随源码发布。回归覆盖资源绑定、开关、回执与编码；公开文档不包含真实聊天、联系人或消息编号。
