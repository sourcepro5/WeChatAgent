# 发布范围

本目录为 WeChatAgent 0.2.0 公开源码工作树，保留既有 Git 历史。不要提交 state/、release/、node_modules/、真实配置、数据库、凭据或日志。五份授权人格作为预设明确包含。开发测试和合成数据生成器不随此副本分发；开发探针测试及其入口也已移除，保留环境、数据库与真实发送后端检查。

构建工具从根 package.json 安装；第三方 Hook、微信、DSH 及运行环境作为外部组件，安装器单独上传 GitHub Releases。

发布前运行 npm run privacy:check，并核对构建依赖与组件来源。隐私扫描检查候选提交文件、禁止的文件类型和明显凭据字面量；维护者另行比对本机实际标识，扫描不能替代人工核验。

此次本地整理不执行 GitHub 推送。原工作树与暂存差异的备份保存在开发机私有 state/public-sync-backup 下，不复制进本仓库。
