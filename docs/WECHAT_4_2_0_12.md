# 微信 4.2.0.12 实验适配

此适配仅面向 Windows x64 **4.2.0.12**，仍为本地实验状态。默认配置和安装包继续使用原配套版本，其他 4.2 构建不自动视为兼容。

## 已验证范围

2026-11-01 完成腾讯签名客户端核对、离线映射、原生对象构造与释放、公开 NT 读取器、真实读取 API 和 OneBot 账号/版本检查。经维护者明确授权，向文件传输助手发送过且仅发送过一条固定自测文字，取得新的本账号发出记录及非零服务器消息 ID。没有给其他聊天发送消息，没有调用模型。

651 项隔离回归通过，旧版本的账号、版本、启动与客户端保护边界继续保留。非微信宿主拒绝初始化的检查通过。

图片和真实 @ 仅完成构造探测，未做本项目内实发验收；普通文件、表情与原生引用发送不因本适配自动新增。群聊、长期运行和模型回复链路仍需单独验收。

## 启动稳定性

首次早期加载曾出现组件栈溢出。后续热加载、重复构造和真实文字收发通过。当前源码增加了图形初始化等待、大路径缓冲的堆分配、受控 HTTP 工作线程及后台线程栈保留。

这些后续启动修正已通过编译和隔离回归，**冷启动实机复测尚待完成**。不得把单次热加载成功视为正式替换验收完成。

## 本机构建与使用

单独准备获授权且精确匹配的客户端与头文件依赖，执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/build-hook.ps1 -TargetVersion 4.2.0.12
```

输出位于私有 `state/hook/native-4.2.0.12/`。选择新版时使用 `hook.expectedVersion: 4.2.0.12` 和项目 `state/hook/` 下对应的独立客户端路径；原有配置不自动切换。打开流程使用专用装载脚本，继续核对腾讯签名、组件哈希、精确版本、原生结构、进程归属和单账号状态。

客户端保护按目录独立保存权限及更新器恢复记录，维护前先解除对应目录的保护。程序目录分离不等于账号数据分离；测试前应备份账号数据库、共享配置和用户设置。

此实验没有上传二进制、凭据、账号标识、数据库或原始回执。现有发行版、发布标签和稳定分支均不在本次实验中替换。
