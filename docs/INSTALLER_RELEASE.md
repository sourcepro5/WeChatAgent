# Windows 安装发行版

安装器名称 WeChatAgent-Setup-0.2.0-x64.exe，包含独立桌面程序和维护者已授权的运行组件。DSH 与插件 SDK 目标为 0.2.0-rc.2。

此源码副本不包含安装器或 vendor 程序。由维护者将安装器、SHA256SUMS.txt 与验证记录作为 GitHub Releases 附件上传。

当前用户级安装，默认无需管理员权限；首次运行准备用户工作区及运行环境。首次白名单为空，用户需登录自己的微信、DSH 并填写有效读取凭据。所有当前人格按用户明确要求作为预设；已有用户编辑保留。

建议预留至少 6 GiB 空间。运行环境按版本和内容哈希分目录，升级保留账号配置、凭据与人格；卸载保留用户数据。首次复制使用原始文件系统处理 ASAR，升级使用保留 AppData 的标准替换路径，并清理长路径程序文件。

现有安装包未商业代码签名。维护者的安装／启动／更新／卸载验收为 Windows 11 本机隔离目录，不代表已在每台电脑或每个账号验收。
