# Windows 安装发行版

安装器为 WeChatAgent-Setup-0.2.1-x64.exe，包含独立桌面应用、Node.js、Python、读取依赖及维护者已授权的微信、发送与自动连接组件。DSH 桌面端与插件 SDK 锁定 0.2.0-rc.2。

此源码副本不包含安装器或 vendor 程序。安装器、SHA256SUMS.txt 与 VERIFICATION.json 作为 GitHub Releases 附件单独上传，release/、state/ 和第三方二进制继续排除在 Git 源码提交外。

## 首次使用

打开匹配微信，点击“自动查找账号”，选择当前账号，再点击“一键连接并验证”。也可选择包含 db_storage 的账号文件夹、db_storage 或 xwechat_files。程序先验证已有凭据，缺失或失效时自动获取；获取期间需要在微信完成登录，若一直等待可退出账号后重新登录。

数据库实际读取验证通过后，凭据使用当前 Windows 用户保护并安全保存；失败保留输入和原配置，并显示可执行的恢复步骤。手动密钥填写保留在高级选项。然后登录 DSH、启用本机插件、启动服务，选择允许的好友或群聊。首次聊天范围为空。

## 源码构建

从根 package.json 安装独立构建依赖。维护者需另外准备已授权的微信、Hook、DSH 程序及 components/weflow-cli/resources/key/win32/x64/wx_key.dll；这些程序不进入公开 Git 源码。

安装器版本读取根 package.json。构建会包含所有读取器需要的 Python 模块、文字发送记录模块、自动配置辅助模块和 wx_key.dll；内置环境检查同时核对这些组件的存在及读取器导入。

## 数据与验证范围

当前用户级安装。用户数据保存在当前用户 AppData 下的 WeChatAgent 工作区，运行环境按版本与内容哈希隔离。升级保留配置、凭据、人格编辑和私有状态；卸载保留用户数据。建议预留至少 6 GiB 空间。

源码及安装包不包含维护者的账号、密钥、聊天或本机配置。授权人格作为预设包含，用户自己的编辑会保留。

完整开发回归 163 项通过；首次配置使用模拟账号验证多账号选择、失败恢复、验证后保存及浅色／深色主题。加密模拟数据库验证通过且源内容不变。包内模块、组件与摘要校验记录在 Release 的 VERIFICATION.json；它同时区分历史安装验收与当前构建检查。尚未完成另一台电脑或其他真实账号的登录取密钥及收发验收。安装包未商业代码签名。
