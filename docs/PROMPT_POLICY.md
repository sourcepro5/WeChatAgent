# 提示词与上下文规则

系统预设只定义本机人格、权限边界和最终回复要求；消息条数由当前会话布局控制，不再同时要求“一条短消息”和“两条文字”。固定规则在会话初始化时提供，扩展说明沿用可替换槽位，不在每一轮追加副本。

联网搜索保留简短稳定说明，仍由模型结合对话自主决定是否调用，不依赖网址或固定关键词。网页阅读只在本轮有授权链接时提供说明；Bilibili 和诛仙世界行情页的专用规则按来源域名加入，其他网页不携带这些站点细节。工具权限、次数、来源校验和回执逻辑保持原样。

上一条已发送回复仅在原生有效历史中仍有完全相同的短文字时省略副本。发送未确认、内容被改写、分条或带图，以及历史已被压缩时保留接话依据；不删除聊天历史，不改写受保护的首条系统消息。

时间提示的时区由 `wechat.time_zone` 决定：留空使用 `Asia/Shanghai`，填写 IANA 时区名（例如 `Australia/Sydney`）后按该时区输出日期、时间和星期，避免跨时区时日期整体错一天。面板提供按城市列出的常用时区，其余时区按 IANA 区域分组；非法时区会退回北京时间，不会让提示词构造失败。

规则升级通过既有初始化替换机制生效，人格不变时不会宣称身份发生变化。启用更新后的源码时，先在项目目录执行 `node scripts/project-config.mjs` 刷新插件修订号，再从托盘完整退出并重开 DSH，最后重启 WeChatAgent 服务，无需归档或重建会话。首次规则切换会改变上下文前缀；输入字符减少不等于承诺缓存命中率提高。

回归命令：`npm run test:prompt-policy`、`npm run test:time-zone`。测试使用临时配置和模拟模型，不发送真实微信消息。
