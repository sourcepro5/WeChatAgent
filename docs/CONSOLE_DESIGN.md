# 控制台设计

面向日常管理本机微信助手的用户；首屏回答“是否就绪、怎样启动、哪里需要处理”。参考 FlClash 的桌面导航和控件密度，不引入代理软件功能。

## 视觉约定

- 背景 Mist `#F3F5F4`，卡片 Paper `#FFFFFF`，文字 Graphite `#26332E`，次要文字 Slate `#627068`，边框 Fog `#E1E7E3`，强调色 Pine `#426B58`。
- 深色使用同一组语义变量：灰绿色底、浅文字、柔和绿色强调。
- 标题使用 Segoe UI Variable Display / 微软雅黑；正文 Segoe UI / 微软雅黑；数字使用 Cascadia Mono / Consolas。使用系统字体，不依赖联网加载。
- 桌面侧栏 196px，主区最大 1160px；卡片圆角 14px，控件 38px，图标 18px，间距 8/12/16/24px。移动端控件至少 44px。
- 特征元素是首页的“连接检查”线路：微信读取、消息桥接、模型连接三个实际状态节点；不画虚构流量图。

```text
侧栏         标题                       主题 / 刷新
概览         [运行状态 / 启停]           [回复方式]
聊天范围     [读取 ─── 桥接 ─── 模型连接]
人格         [缓存统计] [已允许好友] [已允许群聊]
会话         [最近记录]                 [当前设置]
回复设置
连接设置
日志
工具
```

方案自查：技能数据库的通用建议偏营销页，因此仅采用平面设计、真实数据、易读表单和密度原则。取消通用渐变、巨大 KPI、装饰图表及营销式标题；保留本项目真实连接链路和日常动作。

## 交互约定

配置编辑先保存，再明确重启应用。所有编辑保留未知配置项，自动备份并检查版本冲突；不在打开页面时重启服务。模型或插件端口更新后提示完整重开 DSH。脚本操作通过固定任务列表执行，显示进度和可读错误。首启配置、联系人检索、人格文本编辑、会话压缩、维护脚本均提供表单或按钮。
