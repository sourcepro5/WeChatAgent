# 按需联网搜索与单轮次数限制

2026-10-07。核心搜索独立于人格卡，全局和每聊天开关保存后生效，公开示例默认关闭。Bridge 从固定的 HTTPS Bing RSS 端点获取标题、链接和摘要，不抓取整篇网页，不执行网页指令，不批量上传聊天历史。

## 单轮限制

| 设置 | 默认值 | 可设置范围 |
| --- | --- | --- |
| 每轮回复最多联网搜索 | 1 次 | 1–3 次 |
| 每轮摘要长度 | 1,200 字符 | 256–3,000 字符 |
| 摘要结果数 | 3 条 | 1–3 条 |
| 每个搜索请求超时 | 8 秒 | 1–12 秒 |
| 普通摘要缓存 | 15 分钟 | 1–60 分钟 |

**不设每日总次数、单聊天每日次数或每日 token 预算。** 新一轮回复可以继续搜索。合并消息包含多个明确查询时，按每轮上限选择最近的不同问题，最多查询 1–3 次；重复查询会去重。缓存命中不发起新的联网请求，天气、价格等实时信息最多缓存两分钟。

同一轮使用稳定批次 ID，搜索请求在发起前持久化计数。失败不自动重试；重复接收、失败重放和进程重启不会再次搜索同一个批次。每张搜索票据只准许一次搜索模型请求，不增加额外的规划模型调用。

次数限制不能固定每次模型费用；每轮的实际 token 消耗仍由模型和原会话上下文决定。程序保留摘要长度限制，并在本轮完成后将完整摘要从后续有效上下文替换为短说明，避免反复提交长网页资料。

## 触发和回复

明确的“帮我搜”“查一下”等请求，以及天气、最新信息等带提问意图的消息可以触发。普通闲聊、转发历史里的搜索指令、仅在引用原文里出现的搜索请求不触发。要求查“这个”且引用了文字时，可取有界引用片段构成查询，每个查询最长 80 字符。

查询结果经去重、链接过滤、转义和截断后，作为历史资料提交给同一个 DSH 原生回复会话。资料不足时说明不确定，并优先提供最相关的一个来源。只开放固定搜索通路，既有文件、命令和其他工具限制继续生效。

超时、空结果或接口不可用时正常结束这一轮，仍可回复不依赖实时资料的部分，不堵住聊天队列，也不声称已核实实时信息。搜索模型请求已经使用时，不再重复该请求；必要时只做一次没有搜索摘要的普通回复。

## 模型参数兼容

原实现给搜索轮强设 reasoningEffort: none，而当前 deepseek-account / deepseek-flash 不支持这个值，因此会在模型请求准备阶段失败。本版移除对搜索轮推理档和输出 token 参数的强制覆盖，保留当前模型原有设置。旧实现留下的临时参数恢复记录，会在下一次请求前还原并清理。

DSH 健康接口报告 searchBudget: per-turn-count-v1、searchReasoning: model-default-v1 后，Bridge 才启用新模式。插件加载入口附带本机代码的内容版本号，相关搜索模块沿用该版本号，避免启停插件时重用旧模块缓存。新版可通过 DSH 自带插件管理接口热更新。

## 数据与迁移

使用记录保存在 state/search/state.json，票据使用标记位于 state/search/used/。旧每日台账迁移为版本 3，仅保留缓存和已有批次，不继续执行每日额度检查，不清除已使用票据。损坏记录按搜索不可用处理。

这些本机私有文件可能含搜索查询与摘要，不应发布。关闭搜索或缓存不会删除已保存数据。Bing 的公开摘要入口可能受限流或格式变化影响；失败不会改为无界抓取或无限重试。

## 验证

回归覆盖单轮多查询限额、去重、缓存失效、跨聊天并发、防重复重试、新一轮不受日额度限制、旧台账迁移、来源转义、原模型参数保留和旧错误参数恢复。

真实独立 DSH 会话连续两轮搜索 DeepSeek 与 Python 官方网站，每轮均只发起一次搜索、一次搜索模型请求，均成功输出带官网链接的回复，未再出现不支持 none 的错误。验收未向微信联系人发送消息，所有人格 MD 文件保持不变；私有报告为 state/diagnostics/web-search-per-turn-live.json。
