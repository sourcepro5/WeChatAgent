# 上下文阈值与空闲自动压缩

“回复设置”可以开启自动压缩，默认阈值为 100,000 token，默认空闲等待 60 秒。“聊天范围”可为好友或群聊单独填写阈值：留空继承全局，0 关闭，启用值为 4,000–2,000,000 token。配置保存后生效。

计量使用 DSH 原生 `tokenMeter.measure(session)` 的当前有效上下文，包含缓存输入；不累加历史轮次费用。原生计量可能依据模型 usage 或估算，“会话”页面会注明估算并显示当前大小。阈值用于触发压缩，正在回复或发送时可能暂时超过，不截断输出、不拒绝消息。

Bridge 每 30 秒检查已允许的聊天。只有安静时间达到设置、没有未处理消息、模型判断、回复草稿、发送任务或主动聊天草稿时，才取得该聊天共用的运行锁。DSH 再次读取本机设置与消息缓冲，确认指纹未变化，并通过原生 `compactNow` 预留空闲 Agent 后生成摘要。不同聊天仍可正常处理消息。

压缩期间收到新消息会留在缓冲，结束后继续处理。会话 ID、原始日志与人格卡保留；下一次模型请求按现有逻辑恢复一份当前人格。未初始化或已归档的会话不会为自动压缩而新建、换代。

压缩本身会调用摘要模型。每次请求前持久化尝试记录；失败至少等待五分钟，同一段未变化的消息与阈值最多尝试三次。成功或没有可压缩区间时，等待新消息或设置变化，避免反复压缩同一段上下文。普通回复的模型、推理和输出 token 设置保持原有配置。

配置示例：

```json
"context": {
  "enabled": true,
  "maxTokens": 100000,
  "idleSeconds": 60,
  "chats": {
    "wechat:private:123456": 50000,
    "wechat:group:654321": 0
  }
}
```

该字段位于 `wechat` 下。首次安装的示例配置默认关闭自动压缩，由所有者选择开启。
