# 语音对话 API 1.7.0

为 WeChatAgent 提供三项语音能力：把 DSH 生成的回复读成微信语音，以及把收到的微信语音转成文字交给 DSH。人格、会话上下文、回复正文和文字／语音的选择仍由 DSH 负责。每项能力都可以接入任意一家已支持的语音服务，或接入兼容的自定义 API；三项能力可以分别使用不同的服务。

需要支持 `voice-output-v1`（语音合成）和 `voice-input-v1`（识别微信语音）的 WeChatAgent 宿主；兼容旧版的“语音直接对话”另外需要 `voice-dialogue-v1`。

## 三项语音能力

| 能力 | 输入 → 输出 | 测试方式 |
| --- | --- | --- |
| 语音合成 | DSH 已生成的回复正文 → 语音音频，再发成微信原生语音 | 生成测试语音并试听 |
| 实时语音识别 | 一条已录好的微信语音按服务的实时协议分段提交 → 中间结果和最终转写 | 测试实时识别，显示中间结果 |
| 单条语音识别 | 一条完整的微信语音作为文件提交 → 一次最终转写 | 测试识别 |

实时识别和单条识别可以同时保存配置。在“收到语音时使用”中选用其中一种（或不识别）：每条微信语音只按选用的方式提交给一个服务，最终转写只交给 DSH 一次。设置页的三行摘要显示各项能力使用的服务，并标出正在用于识别的那一项。

## 设置页

设置页是三行摘要，每项能力一行：语音合成、实时语音识别、单条语音识别。每行显示当前使用的服务、模型（语音合成还显示音色）和状态（未配置、缺少凭据、已配置、测试通过、测试失败），右侧是“试听”或“测试”，以及“添加”或“编辑”。

- **添加／编辑**：只展开这一项。顶部用两个页签选择来源：
  - **第三方模型提供商**：选择服务后，默认只需要填写凭据、选择模型和音色（个别服务还需要 APPID 或区域）。服务地址、接入方式、协议和语速等收在“更多设置”里，按需展开；改过默认值时会自动展开。
  - **自定义 API**：选择接口协议，填写地址、密钥和模型。服务名称、鉴权方式和超时在“更多设置”里。适用于本机语音服务、自建网关和其他兼容服务。
  - 切换页签不会丢掉另一边填过的内容；在另一个页签里选定服务之前，当前服务保持不变。
- **模型和音色**：各用一个选择框。列表中没有时，选“手动填写 ID…”直接输入；一家服务有多种接入方式时，模型按接入方式分组，选模型的同时就选定了接入方式。支持的服务可以“读取模型和音色列表”。
- **试听／测试**：语音合成用内置短句生成语音并播放；语音识别用内置录音，实时识别会显示中间结果。结果显示在该行下方，只说明服务可用，不会发送任何消息。
- **收到语音时使用**：在三行下方选择实时语音识别、单条语音识别或不识别。两种识别可以都配置好，每条语音只交给选用的那一种。
- **聊天授权**：展开后可查看已保存的启用状态和授权聊天；修改在窗口上方的“授权能力与聊天”中进行。
- **高级设置**：回复的生成方式、语气指令和默认超时。

使用步骤：在“能力 → 能力目录”导入 `speech-synthesis-1.7.0.zip`，打开插件配置，勾选“允许此插件运行”；逐项添加并测试；在“授权能力与聊天”中勾选所需权限、选择聊天，然后点“保存插件设置”。展开项里的“完成”只是收起，修改在保存插件设置后生效。

各服务的接入要点：

- **腾讯云语音**：凭据为 SecretId 和 SecretKey。合成与一句话识别使用 TC3-HMAC-SHA256 签名；合成单次最多 150 个汉字，较长的正文分段合成后拼接，地域可选。实时识别需要填写 APPID，连接地址按官方方法用 HMAC-SHA1 签名；服务端每秒最多接收 3 秒音频，插件按 2.5 倍速分段发送，60 秒的语音约 24 秒发完。
- **千问 / 阿里云百炼**：凭据为 API Key；使用阿里云百炼业务空间时可改用业务空间域名。语音合成流式返回 16 kHz 音频，语速 0.5–2.0；Realtime 朗读和语音合成各自保存模型和音色，切换时互不覆盖。实时识别可选 Realtime 会话转写（在会话中指定转写模型，如 fun-asr）或 Qwen-ASR-Realtime；单条识别以 Base64 Data URL 提交录音。
- **OpenAI**：凭据为 API Key。实时识别使用 Realtime 转写会话（24 kHz PCM）。OpenAI 已宣布 `tts-1`、`tts-1-hd`、`gpt-4o-mini-tts` 将于 2027 年 1 月 6 日停用；使用其官方语音时，请告知听众语音由 AI 生成。
- **硅基流动**：凭据为 API Key，使用 OpenAI 兼容的 `/audio/speech` 和 `/audio/transcriptions`，国内可直接访问。
- **ElevenLabs**：凭据为 API Key。合成输出 `wav_16000`，语速 0.7–1.2；可从账号读取音色和模型列表。
- **Azure AI Speech**：凭据为资源密钥和区域（需与语音资源一致）。合成使用 SSML，短音频识别限 60 秒以内。
- **Google Cloud Speech**：凭据为服务账号 JSON，插件在本机换取访问令牌，不支持 API Key。
- **智谱、阶跃星辰**：凭据为 API Key，提供 Realtime 朗读。
- **Realtime 朗读**（OpenAI、千问、智谱、阶跃星辰）：Realtime 模型只逐字朗读 DSH 的正文，不自行生成回复。平台返回错误时，测试结果会附上平台的错误码和出错参数。

依据：[腾讯云 TextToVoice](https://cloud.tencent.com/document/api/1073/37995)、[腾讯云 SentenceRecognition](https://cloud.tencent.com/document/api/1093/35646)、[腾讯云实时语音识别（WebSocket）](https://cloud.tencent.com/document/product/1093/48982)、[腾讯云签名方法 v3](https://cloud.tencent.com/document/api/1073/37990)、[千问 Qwen-Audio-TTS HTTP API](https://platform.qianwenai.com/docs/api-reference/speech-synthesis/qwen-audio-tts/http-api)、[Qwen-ASR-Realtime 服务端事件](https://platform.qianwenai.com/docs/api-reference/speech-recognition/qwen-asr-realtime/server-events)、[Qwen-ASR API 参考](https://platform.qianwenai.com/docs/api-reference/speech-recognition/qwen-asr/api-reference)、[ElevenLabs Create speech](https://elevenlabs.io/docs/api-reference/text-to-speech/convert)、[Azure 文字转语音 REST](https://learn.microsoft.com/azure/ai-services/speech-service/rest-text-to-speech)、[Google Text-to-Speech](https://docs.cloud.google.com/text-to-speech/docs/reference/rest/v1/text/synthesize)。

## 声音复刻

所选语音合成方式支持声音复刻时，“选择模型及音色”下方会出现“声音复刻：创建自定义音色”：选择 10–20 秒的清晰单人录音 → 上传并创建 → 查询审核状态 → 审核就绪后“使用此音色” → 试听并保存。

- 录音只在点击上传后提交，且只提交到当前语音合成服务的账号。
- 复刻音色绑定创建时的模型，只能用于该模型；绑定其他模型的音色会被拒绝。切换合成模型后需要为新模型另建音色。
- 目前接入复刻的是千问 / 阿里云百炼的语音合成与 Realtime 朗读（[音色复刻说明](https://platform.qianwenai.com/docs/developer-guides/speech/voice-cloning)）；其他服务的复刻音色可在其控制台创建后，直接填写音色 ID。

## 自定义模型 API

| 能力 | 可选协议 |
| --- | --- |
| 语音合成 | 语音合成（OpenAI 兼容 `/audio/speech`）；Realtime 朗读（WebSocket，OpenAI 正式版或测试版事件） |
| 实时语音识别 | 实时语音识别（Realtime 转写会话，OpenAI 格式）；实时语音识别（DashScope 格式，text + stash 中间结果）；Realtime 会话转写（`input_audio_transcription`） |
| 单条语音识别 | 录音文件识别（OpenAI 兼容 `/audio/transcriptions`） |

- 只填基础地址时自动补上接口路径；已包含 `/v1`、网关前缀（如 `https://gw.example.com/openai/v1`）或完整接口路径（含查询参数）的地址按原样使用。
- 鉴权可选 `Authorization: Bearer`、自定义请求头或无需鉴权；WebSocket 协议只支持 Bearer 或无需鉴权。超时可单独填写，留空使用高级设置中的时间。
- 模型列表是可选功能：服务不提供 `/models` 时，测试显示“已连接”，模型和音色直接填写。

## 凭据

- 每项能力保存一份凭据，并记录它属于哪个服务（自定义 API 记录保存时的地址）。两项能力使用同一服务时，可以直接沿用另一项已保存的凭据。
- 凭据只发往所属服务的官方地址；自定义 API 的凭据只发往保存时的地址（协议、主机和端口），地址改到别处后需要重新填写。切换服务时，原凭据不会发给新地址。
- 设置页不会回显已保存的凭据；页面会说明每项能力将沿用哪一份凭据。

## 从旧版升级

旧版配置（1.5.0 及更早的平铺设置）在打开时自动按能力拆分，保存后按新格式写入；重复读取得到相同结果：

- 旧版的 Realtime 朗读成为“语音合成 · Realtime 朗读”，原模型和音色（包括复刻音色）不变；旧版在 Realtime 会话中的转写成为“实时语音识别 · Realtime 会话转写”，识别方式为实时识别。
- 旧版普通语音 API 的合成和识别，分别成为“语音合成”和“单条语音识别”。地址都属于同一家已支持服务的，恢复为该服务；其余按自定义 API 读取。
- 原来保存的密钥继续由识别出的服务使用；原有地址、模型、音色、语速、协议、回复方式、启用状态、权限和聊天绑定保持不变，当前聊天可以继续收发语音。
- 1.5.0 中按提供商单独保存的密钥栏改为按能力保存。升级前请确认这些栏没有单独填写的密钥；如有，升级后在对应能力中重新填写。

## 高级设置

- **回复的生成方式**：默认由 DSH 生成回复。“语音直接对话”（不经过 DSH，兼容旧版）只在语音合成选用 Realtime 朗读时可用。
- **语气指令**：设定朗读的语气或风格，由 Realtime 模型和支持语气指令的合成服务使用。
- **等待服务响应的最长时间**：默认 20 秒，自定义 API 可单独设置。

## 1.4.0 逐轮选择文字或语音

- “语音直接对话”改为由模型逐轮决定回复形式：同一聊天里，收到文字或语音后，模型先输出 `{"mode":"voice"|"text","text":"…"}`，选语音时再把这段正文读成语音。用户明确要求“用语音回答”“念给我听”“打字发我”时优先照做；代码、链接和需要复制的内容用文字。
- 收到文字消息也会触发：私聊直接处理；群聊里的文字需要 @ 本账号。语音消息沿用原有的群聊触发方式。
- 模型输出必须是可解析的 JSON，回复正文不超过 600 字，读成语音的正文不超过 400 字。无法解析时记录错误代码并结束本轮，不发送任何内容。选了语音但合成确定失败时，改发一次同样的文字。
- 本轮能否发语音由 WeChatAgent 的发送后端决定。后端不能发语音时，模型只会被告知可以回文字。
- “测试对话（查看回复形式）”用内置短句运行一轮，显示模型选择的形式和正文，选语音时可试听，并标注该平台是否已实测。测试结果不代表微信投递结果。
- 在“把 AI 的回复读成语音”模式下，宿主也会通过同一插件把 DSH 选定的语音回复读成语音；“语音直接对话”模式下，DSH 的语音回复使用只朗读的实时会话生成。
- 千问预设按官方文档改为 `wss://maas.qianwenaiapi.com/api-ws/v1/realtime`、3.1 模型和带 `_v3.1` 的音色（原预设把 3.1 模型配上了 3.0 音色，会被平台拒绝）。千问现在也接收文字消息。之前保存过 longanqian 等 3.0 音色、又在用 3.1 模型的，重新选一次“千问”平台即可换成可用的音色。
- 已保存的平台预设、音色、语速、实时对话协议和设置页内容升级后原样保留。

## 1.2.0 新手优化

- **按用途选择**：用“把 AI 的回复读成语音 / 语音直接对话（进阶）”代替原来的“语音模式”。
- **平台预设和音色列表**：选择平台后自动填写地址、模型和音色；音色可从下拉中选择，也可以填写其他音色 ID。
- **语速**：新增语速滑块（0.5–2.0，默认 1.0）。语速为 1.0 时请求中不带 `speed`，与旧版行为相同。
- **自动整理密钥、检查地址**：自动去掉 `Bearer `、引号、`API_KEY=` 等；地址缺少 `https://`、贴成网页控制台地址、贴成密钥、只有域名、贴成其他接口地址时会提示并提供一键修正。
- **报错指出具体字段**：测试前先检查缺了哪一项；平台报错时在对应栏目下标出原因。错误说明改成白话，例如“这个模型没有返回可用的 WAV 音频，请换一个语音模型或平台”。
- **模型列表分组**：读取的完整模型列表中，名字像语音模型的排在“推荐”分组。
- **试听更完整**：试听最长 5 秒（原来 1.25 秒），测试成功后显示保存指引。试听使用低码率，实际发送的语音不受影响。
- **识别设置单独折叠**：“同时用它识别微信语音（可选）”收进折叠区，并说明已使用“语音识别 API”插件时保持留空。已保存的识别设置原样保留。
- **超时按秒填写**。
- 已保存的设置和密钥升级后原样保留；合成、识别和实时对话的请求方式不变。设置页不能打开外部网页，获取密钥的网址需复制到浏览器打开。

## 数据与权限

- 凭据按能力保存在受宿主遮蔽的设置项中（腾讯云的 SecretId 和 SecretKey、Google 服务账号 JSON 也一样），只发往所属服务的地址。
- 密钥只保存在本机插件设置中，设置页不会回显已保存的密钥，测试结果中也不会包含密钥。
- 测试使用内置短句或内置测试音频，不使用聊天内容，可能消耗少量服务额度。
- `audio_synthesize`：生成要发送的微信语音。`audio_read`：仅在启用识别或语音直接对话时读取当前收到的微信语音。
- 语音直接对话会把当前收到的这一条文字或语音交给所选平台，不附带聊天记录。插件日志只记录阶段和错误代码，不记录密钥、原始音频和聊天正文。

参考：[OpenAI 语音合成接口](https://developers.openai.com/api/reference/resources/audio/subresources/speech/methods/create)、[OpenAI Realtime 语音会话](https://developers.openai.com/api/docs/guides/realtime-conversations)。
