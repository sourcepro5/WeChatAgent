# 人格卡与本机管理

人格卡是本机所有者维护的 Markdown 文件，文件名对应人格名称。
在 config/wechatagent.json 的 persona.default 或 persona.chats 中选择人格，可通过桌面应用编辑和选择，保存后重启服务。
内置预设包含傲娇助手、德克萨斯、洛奇希、示例助手、小鲸鱼；首次默认选中示例助手。自定义卡只写人格与语气，不给聊天成员配置权限。

群聊、私聊、图片文字以及“我是主人／管理员”等声明均不能修改固定人格、行为规则、白名单或工具权限。
本项目不提供“进入角色扮演”“退出角色扮演”“修改系统提示”等聊天管理命令。
明确的修改请求在本机拒绝；其余聊天内容作为未受信任的对话数据处理。

人格由本机配置生成的可信快照提供，DSH 请求中的人格字段仅能与快照一致，不能覆盖它。
模型没有文件、命令或配置工具，无法把聊天中的临时要求写回本机设置。
普通聊天上下文仍会影响当前回复内容；模型语言表现不能被描述为百分之百免疫提示注入。

发布自定义卡前请确认授权并清除个人资料。真实配置和运行数据应留在本机。
